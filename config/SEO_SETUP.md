# پنل بررسی سئو

صفحهٔ `/admin/seo/` فقط برای مدیر کل سایت در دسترس است. آمار نوشته‌ها و نمونه‌کارها از پایگاه داده می‌آید؛ وضعیت عمومی دامنه با درخواست HEAD به `https://sitarogroup.ir/` بررسی می‌شود و پنج دقیقه کش دارد. این شاخص، جایگزین پایش دائمی uptime یا بررسی کامل سئوی فنی نیست.

## اتصال Google Search Console

1. در Google Cloud یک Service Account بسازید و Search Console API را در همان پروژه فعال کنید.
2. ایمیل آن حساب را در property دقیق `https://sitarogroup.ir/` در Search Console با دسترسی خواندن اضافه کنید. اگر property ثبت‌شده از نوع Domain است، مقدار پیکربندی را دقیقاً به‌شکل `sc-domain:sitarogroup.ir` تغییر دهید.
3. فایل JSON اعتبارنامه را **بیرون از مخزن** و با دسترسی فقط برای فرایند سرور نگه دارید. کلید را در گفتگو، کد یا Git قرار ندهید.
4. روی سرور این متغیرها را تنظیم کنید:

   `SITARO_GSC_SITE_URL=https://sitarogroup.ir/`

   `SITARO_GSC_CREDENTIALS_FILE=/path/outside/repository/service-account.json`

   در اجرای Docker، فایل را به‌صورت read-only در کانتینر mount کنید و مسیر داخل کانتینر را در متغیر دوم بگذارید.
5. پس از نصب وابستگی‌های `requirements.txt` و راه‌اندازی مجدد برنامه، صفحهٔ `/admin/seo/` را باز کنید. اگر اتصال برقرار باشد، کلیک، نمایش، نرخ کلیک و میانگین رتبه برای آخرین ۲۸ روز کامل نمایش داده می‌شود (سه روز اخیر برای تأخیر داده‌ها کنار گذاشته می‌شوند). نتیجهٔ موفق ۱۵ دقیقه کش دارد.

بدون فایل اعتبارنامه یا دسترسی property، پنل عمداً داده‌ای تخمینی نمایش نمی‌دهد.
